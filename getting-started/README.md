# Getting started with Google Colab

Complete these short steps before your first class. No previous experience with Python or Google Colab is required.

## What is Google Colab?

**Google Colab** is an online service for opening and running Jupyter notebooks through a web browser. You do not need to install Python on your computer.

A **Jupyter notebook** is an interactive document containing Python code, explanatory text, results and figures. Notebook files use the extension `.ipynb`.

In short:

> **Python** is the programming language → a **Jupyter notebook** is the interactive document → **Google Colab** opens and runs it.

## 1. Choose a Google Account

You need a Google Account to save and edit notebooks in Google Colab.

You may use:

- an existing personal Google or Gmail account; or
- a Google Account created using your Maynooth University `@mu.ie` email address.

To use your Maynooth University email address, [create a Google Account](https://support.google.com/accounts/answer/27441) and select **Use your existing email**.

A Google Account created using an `@mu.ie` address is separate from your Maynooth University Microsoft 365 account.

Use the same Google Account throughout the course.

## 2. Open the test notebook

The test notebook is stored on GitHub as:

[`00_test_google_colab.ipynb`](../notebooks/00_test_google_colab.ipynb)

Select the button below to open it directly in Google Colab:

[![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/shaunharrigan/maynooth-geo-python/blob/main/notebooks/00_test_google_colab.ipynb)

The notebook will confirm that you can run Python code and display a simple figure before the first class.

## 3. Save your own copy

When the notebook opens in Google Colab:

1. Sign in using your chosen Google Account.
2. Select **File → Save a copy in Drive**.
3. Continue working in your own saved copy.

Colab will normally save the copy in a Google Drive folder called **Colab Notebooks**.

The notebook stored on GitHub remains unchanged. Your editable copy is stored separately in Google Drive.

## 4. Run the test

Follow the instructions inside the notebook.

To run a code cell:

1. Select the cell.
2. Press the **play button** beside it or press **Shift + Enter**.
3. Check that the expected output appears beneath the cell.

If you can open the notebook, save your own copy and run its code cells, you are ready for the first class.

## Before your first class

Confirm that you can:

- sign in to Google Colab;
- open the test notebook;
- save your own copy in Google Drive;
- run a code cell and see its output.
