# Python for Geographical Data Analysis

![Python for geographical data analysis across climate, environment and society](maynooth_geo_python_banner.png)

Practical Python learning resources for geographical data analysis at Maynooth University.

Developed to support:

- **GY674: Earth Science Data Analysis in Python**
- **GY675: Visualising Inequality**

The resources may also be useful to postgraduate researchers and staff who are new to Python and data analysis.

## Start here

New to the course or to Python? Follow these three steps:

### 1. [Get set up with Google Colab](getting-started/README.md)

Set up Google Colab, Google Drive and your course folders before beginning.

### 2. [Course notebooks and worked examples](notebooks/)

The main teaching materials for the modules, combining explanations, code demonstrations, guided exercises and geographical data-analysis examples.

Begin with the Google Colab test notebook. Additional notebooks and worked examples will be added as they are released.

### 3. [Use the Python Quick Reference Guide](quick-reference/README.md)

Look up Python fundamentals, NumPy, Pandas, Xarray, data visualisation, debugging and reproducible notebook practices.
