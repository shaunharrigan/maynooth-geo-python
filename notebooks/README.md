# Course notebooks

These interactive Python notebooks provide the main teaching materials for GY674 and GY675.

The notebooks combine explanations, code demonstrations, guided examples and exercises using geographical, environmental and social data.

## How to use a course notebook

The `.ipynb` files in this folder are the course master notebooks stored on GitHub.

To work with a notebook:

1. Select the notebook filename to open it on GitHub.
2. Select **Open in Colab** at the top of the notebook.
3. Sign in to your Google Account if prompted.
4. In Colab, select **File → Save a copy in Drive**.
5. Continue working in your own saved copy.

You can open and copy the course notebooks, but you cannot change the original files in this repository. Changes made in your Google Drive copy do not affect the GitHub master.

> You do not normally need to download the `.ipynb` file manually. A downloaded copy may be required later for backup or submission.
