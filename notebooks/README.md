Interactive Python notebooks for GY674 and GY675 will be added here.

## Test Google Colab

Use the test notebook to confirm that you can open, save and run a Python notebook before the first class.

[![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/shaunharrigan/maynooth-geo-python/blob/main/notebooks/00_test_google_colab.ipynb)

When the notebook opens:

1. Sign in to your Google Account.
2. Select **File → Save a copy in Drive**.
3. Run the notebook cells from top to bottom.

The original notebook remains stored on GitHub. Your editable copy is saved separately in Google Drive.
